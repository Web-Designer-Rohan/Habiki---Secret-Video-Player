Hibiki / privacy

Privacy, kept local

Hibiki is built for a personal library on your own device. This page describes what the current application stores and what it does not collect.

LOCAL ONLY

No analytics · No advertising · No cloud sync · No telemetry · No user tracking

01 / activity

Viewing data

When you use the authenticated activity features, Hibiki stores Continue Watching progress, Favorites, and Playback History in the local SQLite database. This includes episode identifiers, anime identifiers, season and episode numbers, playback positions, and timestamps.

02 / preferences

Your settings

Hibiki stores application configuration locally, including the configured default language and player or dashboard settings. The authenticated settings API can also store user preference key/value pairs in the local SQLite database. Changing the language selector in the current UI changes the active page state; it is not sent to a cloud service.

03 / authentication

Local accounts

Local authentication stores usernames, securely hashed passwords, roles, and opaque session records in the local database. Passwords are not stored in plaintext. Authentication is not connected to an online identity provider.

04 / library

Media metadata

The backend stores locally generated library metadata in JSON, including titles, seasons, episode details, and indexed local media references. Your media files remain on the configured local filesystem.

05 / never sent

No tracking layer

  • Hibiki has no analytics service.
  • Hibiki has no advertising or ad profiling.
  • Hibiki has no cloud synchronization.
  • Hibiki has no telemetry or background reporting.
  • Hibiki does not track users across websites or devices.
  • Hibiki does not transmit your library, watch history, favorites, credentials, or settings to a remote Hibiki or third-party server. Login and authenticated activity requests stay between your browser and the local Hibiki backend you run.

06 / your control

Local responsibility

You control the device, database, configuration, logs, and media folders where Hibiki runs. Back up or remove those local files according to your needs. If you expose the application beyond your trusted device or network, you are responsible for securing that environment.

This page describes the current repository implementation and is not legal advice. Review it again if future versions add remote access, integrations, crash reporting, or synchronization.
